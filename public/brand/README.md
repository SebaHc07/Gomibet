# Identidad GOMIBET

Versión refinada a partir del emblema proporcionado por el responsable del proyecto. Conserva el monograma central, el betabel, las hojas y la naranja. Se redujeron detalles y textos diminutos para mejorar su reproducción en pantalla.

- `gomibet-logo.svg`: logo principal vectorial para fondos claros.
- `gomibet-logo-light.svg`: versión para fondos oscuros.
- `gomibet-symbol.svg`: emblema sin texto.
- `gomibet-logo.png`: versión principal con fondo transparente, 864 × 224 px.
- `/favicon.svg`: versión simplificada del betabel para tamaños pequeños.

Paleta: betabel #892840, acento #B63B54, naranja #E98A27 y verde #48764A.

El emblema se utiliza como identidad visual; las referencias de composición del producto siguen siendo las de su ficha técnica. No se añadieron declaraciones nutricionales nuevas al logo.
